# Changelog

## 1.0.0 — 2026-05-21

### Initial release

- `init` command — interactive wizard to create project-aliases.md
- `install` command — install alias section into Claude Code, Codex CLI, Gemini CLI
- `status` command — show installed state per tool
- `validate` command — scan markdown files for undefined alias tokens
- `update` command — re-sync installed alias configs from source
- Templates for Claude Code (CLAUDE.md + project-aliases.md), Codex CLI (AGENTS.md), Gemini CLI (GEMINI.md)
- Bash installer (install/install.sh) and PowerShell installer (install/install.ps1)
- Full docs: REFERENCE.md, EXAMPLES.md, PHILOSOPHY.md, CUSTOMIZING.md, COMPATIBILITY.md
